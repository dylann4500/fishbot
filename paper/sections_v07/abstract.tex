Six-player Canadian Fish is a decentralised imperfect-information team game in which every action is
public, so the hidden state reduces to the initial deal and the posterior over that deal can be
computed exactly. We develop and evaluate \fishseven{}, the strongest configuration produced in this
project's FishBot lineage. It combines an exact observer-conditioned deal posterior with a fitted
linear ask and declaration policy, a public-history tie-breaking rule that preserves common knowledge
among teammates, an information-denial weighting on contested half-suits, a deduction-state stall
detector in place of an event-count termination rule, and a guarded determinized test-time search.
Evaluation follows a protocol registered in advance and run on sealed holdout material, using
duplicate deal blocks, deal-clustered bootstrap confidence intervals, replication across two disjoint
deal banks as an advance-specified criterion, calibrated detection floors, and mechanical
side-channel controls.

Against \fcheap{}, the cheapest configuration on the \vsix{} frontier and the registered comparison
target, \fishseven{} gains \vsevenBtwoFcheapMag{} percentage points of team win-rate edge
$[\vsevenBtwoFcheapLo, \vsevenBtwoFcheapHi]$ over \vsevenBtwoFcheapN{} sealed games, with the sign
replicating on both banks. The advantage survives partner substitution, cross-play between
independently trained runs, \vsevenDiaRows{} rule dialects, and \vsevenBfourArms{} independently
constructed adversarial searches, none of which found a positive edge at the tested budgets.

\fishseven{} does not, however, measurably outperform a composite configuration assembled earlier in
the same programme (\vsevenBtwoComposite{} $[\vsevenBtwoCompositeLo, \vsevenBtwoCompositeHi]$),
indicating that the architecture work which followed added no measurable strength. Four candidate
mechanisms were experimentally rejected. At the calibrated resolution of this evaluation the policy
class appears locally flat, and we state what evidence a near-optimality claim would require.
