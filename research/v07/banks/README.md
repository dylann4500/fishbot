# FishBot v0.7 — the sealed evaluation material

Written by **phase 2**, before any candidate architecture exists and before anything can be tuned
against it. Regenerated by `engine/seal_banks_v07.py`; the split rule below was fixed in that script
before any phase-2 result was known.

## What a "bank" is here, and what sealing one can mean

A bank in this corpus is a **seed plus a size**. The deals are generated from the deal index and are
never stored: `arena.hpp` draws deal *i* of bank *S* from `mixSeed(S, i·2654435761 + 1)`, so the
first *k* deals of a bank are the same deals however large the bank is played. That makes a bank
cheap to reproduce and impossible to hide, so "sealing" one cannot mean secrecy. It means three
things, and this directory carries all three.

**1. A commitment.** `fish7 bankdigest` folds the six dealt hands and the dealer of every deal a bank
would produce into a 64-bit rolling hash. It plays no game and constructs no policy, so the digest of
a sealed bank can be computed now without learning anything about how any policy performs on it —
which is the only phase-2 contact with the holdout material, and it is recorded as such in
`docs/v07/RESEARCH-LOG.md` §2. Phase 5 recomputes each digest and compares. A match proves the bank
being evaluated on is the bank that was sealed here; a mismatch proves a seed or a size was changed
between the commitment and the evaluation.

**2. A seal the binary enforces.** `engine/src/v07_seeds.hpp` marks every holdout seed `Sealed` with
`unsealPhase = 5`, and `runMatch` (`engine/src/arena.hpp`) refuses to construct a match on such a
seed unless `FISH_UNSEAL_PHASE >= 5` is set in the environment. That check lives in `runMatch` rather
than in a battery script, so it covers every command in the binary and not only the batteries that
remember to call `fish7 seeds --require`. At the end of phase 1 the seal existed only in the script
layer; a battery could simply have forgotten it.

```
$ ./fish7 match --a=v06 --b=v06 --games=2 --seed=7090001
fish: seed 7090001 is SEALED until phase 5 (set FISH_UNSEAL_PHASE to unseal)
$ echo $?
5
```

**3. A split of the adversary bank made by a rule, not by a choice.** The exploiters phase 2 produced
are sorted by row id and assigned alternately: even positions train, odd positions holdout. The rule
is in `engine/seal_banks_v07.py` and was fixed before the results were known, so the split cannot
have been chosen to flatter either half. The train half is plaintext in `train/`. The holdout half is
base64-encoded in `holdout/adversaries-holdout.sealed` with the SHA-256 of its plaintext recorded in
the file header, so it is not readable by eye or by a careless `grep` during phases 3–4 while
remaining exactly verifiable in phase 5.

None of this is cryptography and it does not pretend to be: a determined reader can decode the
holdout half in one command. What it is is a **commitment** — once this directory is committed, the
sealed material cannot be silently changed, and any phase that reads it has to do something
deliberate that shows up in the record.

## Layout

```
train/BANKS.json                    the four training deal banks: seed, size, role, digest
train/adversaries-train.tsv         the training half of the phase-2 adversary bank
holdout/BANKS.json                  the seven sealed deal banks, committed and not played
holdout/adversaries-holdout.sealed  the sealed half of the adversary bank
MANIFEST.sha256                     a checksum over every file above
SEAL.json                           the summary: commit, seeds, counts, plaintext hash
```

## The rule for phases 3 and 4

Use `train/` only. Do not read `holdout/`. Do not set `FISH_UNSEAL_PHASE`. Every seed a battery names
must appear in `engine/src/v07_seeds.hpp`; `fish7 seeds --require=<list>` fails a battery that names
an unregistered or still-sealed bank, and the batteries call it before their first measurement.

Phase 2 itself evaluated every adversary on `7030001`–`7030003`, so those banks are burnt by the time
phase 3 starts. That is deliberate: it is what makes them the training half.
